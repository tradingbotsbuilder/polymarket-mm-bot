# Polymarket Market Making Bot

Production-grade market making bot for Polymarket Perps.

## About the Author
I'm Ahmed Al-Rashid, an independent algo trader based in Austin, Texas.
Originally from Dubai, I came to America for MIT, worked at Jump Trading
and Alameda Research, and now I build open-source trading infrastructure.

This bot implements patterns I learned at Jump — battle-tested in production.

## Why Open Source?
America gave me opportunities most people only dream of. I believe in giving
back. This code is free, use it, fork it, build on it.

If you find it useful, star the repo and share it with others.

## Features
- Streaming-first architecture (sub-100ms latency)
- Inventory risk management
- Dynamic spread optimization
- Production-grade error handling
- Comprehensive logging and monitoring

## Requirements
- Python 3.11+
- Polymarket account with API access
- Redis for state management
- Docker (optional, for deployment)
